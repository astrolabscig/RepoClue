# RepoClue

RepoClue is a command-line tool for discovering, evaluating, and organizing public GitHub repositories.

## Current status

Early development. The current version verifies the CLI structure; repository discovery will be implemented next.

## Requirements

- Python 3.11 or newer
- Git

## Run from source

```powershell
python .\src\repoclue\cli.py
```

## Planned capabilities

- Search public GitHub repositories
- Display useful repository metadata and links
- Filter and rank search results
- Save interesting repositories locally
